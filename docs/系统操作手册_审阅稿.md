# 资产管理系统操作手册

**文档状态：审阅稿 v0.1**
**适用系统：资产管理平台（Asset Portal）**
**编写日期：2026-08-24**
**说明：本文档依据当前系统菜单、页面和权限配置整理，功能可见范围以当前账号权限为准。本文档仅供审阅，未执行部署或远端推送。**

## 1. 系统概览

资产管理平台用于维护资产台账，并覆盖入库、领用退库、借用归还、资产交接、盘点、处置、审批、员工签字和系统配置等工作。

系统遵循以下原则：

- 每项资产以资产编码（资产 ID）作为主要识别依据。
- 资产状态、使用人、位置和业务单据会随操作变化。
- 业务操作由后端校验权限、状态和并发版本，页面只展示当前账号可执行的动作。
- 操作记录按资产维度保留，可靠的操作时间显示到“年-月-日 时:分”；只有日期的数据不补造不存在的时分。
- 资产同步功能启用后，老资产系统是资产基础资料的来源，新系统按每天凌晨 2:00 执行单向同步；新系统业务页面不因同步而锁死。

## 2. 登录与菜单

### 2.1 登录

1. 打开资产管理平台入口。
2. 使用公司 ECP 账号登录并完成身份校验。
3. 登录后进入首页；如果账号没有对应菜单权限，系统会隐藏该菜单或提示无权访问。

### 2.2 顶部菜单

| 菜单 | 主要用途 |
| --- | --- |
| 首页 | 查看资产总览、待办和常用入口 |
| 资产 | 资产列表、入库、领用退库、借用归还、交接、盘点、处置和资产设置 |
| 签字 | 查看待本人确认的领用、借用或交接单据 |
| 审批 | 发起、查看和处理资产业务审批 |
| 系统 | 员工信息、组织架构、员工自助、系统对接和表单管理 |
| 成员授权 | 管理角色和应用权限；仅授权账号可见 |

### 2.3 角色边界

- **应用管理员**：拥有业务、配置和成员授权能力。
- **资产运营**：负责台账、入库、领用、借用、盘点、审批等日常业务，不负责成员授权。
- **应用审计员**：只读查看资产、审批、系统配置和授权说明。
- **员工自助**：查看本人资产，发起本人可用的领用、借用、归还或交接申请，并完成签字。

页面能看到不代表一定能提交操作；新增、编辑、删除、导入、处置、审批和配置均受细粒度权限控制。

## 3. 首页

首页用于快速了解系统当前情况：

1. 查看资产总量、状态分布和待处理业务。
2. 点击统计卡片或快捷入口进入资产列表、审批、签字等页面。
3. 发现统计与列表不一致时，先刷新页面，再检查筛选条件和账号数据范围。

## 4. 资产列表

进入 **资产 > 资产列表**。

### 4.1 查询与查看

1. 在搜索框输入资产编码、名称、分类、序列号、使用人等关键词，点击查询。
2. 点击 **高级搜索**，按状态、分类、位置、公司、部门、使用人和日期等条件组合筛选。
3. 点击列表中的资产编码打开详情。
4. 详情页查看基础信息、当前领用/借用信息、生命周期和操作记录。
5. 通过列表设置调整展示列；列设置只影响当前列表展示，不会修改资产数据。

### 4.2 新增资产

1. 点击 **新增 > 新增资产**。
2. 填写资产名称、分类、位置、品牌/型号、序列号、供应商、金额、购置日期等基础信息。
3. 如果填写使用人，必须选择有效的 ECP 人员并确认部门、公司信息。
4. 点击保存。系统生成或校验资产编码，并写入资产入库记录。

### 4.3 编辑、复制和删除

- **修改**：选择资产后点击 **编辑 > 修改**，只修改允许编辑的字段；处于待签字或审批中的资产不要直接改动关键责任字段。
- **批量修改**：选择多项资产后点击 **编辑 > 批量修改**，提交前确认所有选中行均适用同一修改内容。
- **复制资产**：选择一项资产后点击 **编辑 > 复制资产**，系统复制基础资料并生成新的资产编码；新资产默认未分配。
- **删除**：仅建议删除录入错误且尚未投入使用的空闲资产。已经领用、借用、交接或产生业务历史的资产不要删除，应使用退库、处置等业务流程。

### 4.4 导入与导出

**导入/导出**菜单包含：

- **资产导入**：新增多项资产。
- **更新导入**：按资产编码更新已有资产；模板中留空的字段保持原值。
- **批量领用导入**：按资产编码和 ECP 人员批量领用。
- **全量替换资产**：使用前必须由管理员确认数据范围、资产编码集合和历史影响；不要把它当作日常同步入口。
- **导出资产**：导出当前资产数据用于核对或线下留档。

导入注意事项：

1. 每次最多导入 5000 行。
2. 必填字段、分类、位置、金额和人员必须符合系统校验规则。
3. 资产编码必须唯一；更新或批量领用必须使用系统中已有编码。
4. 发现错误时下载错误明细，修正原文件后重新导入；不要重复提交未修正的文件。
5. 不要在模板中添加批注、合并单元格或修改表头名称。

## 5. 资产入库

进入 **资产 > 资产入库**。

### 5.1 单项入库

1. 点击 **新增 > 新增资产**。
2. 填写资产基础资料、采购信息和入库信息。
3. 点击保存后，系统生成入库单号并记录入库日期、入库人和备注。
4. 需要纸质凭证时，点击 **打印 > 打印入库单**。

### 5.2 批量入库

1. 点击 **新增 > 批量导入**，下载或选择标准模板。
2. 按模板填写资产名称、分类、位置、金额、供应商等字段。
3. 提交后查看校验结果；错误行不会写入，修正后只重新提交错误行。

### 5.3 入库查询与撤销

- 可按入库状态、入库单号、入库日期、入库人、公司和备注查询。
- 入库撤销只用于纠正尚未进入后续业务的错误入库；如果资产已经领用、借用或交接，应先按业务规则处理，不要强行撤销。
- 入库单和资产标签可分别打印；打印前确认选择范围。

## 6. 领用退库

进入 **资产 > 领用退库**。页面包含员工申领、领用、退库和交接相关记录。

### 6.1 领用

1. 选择状态为空闲的资产，点击 **领用**。
2. 选择领用人，确认公司、部门、领用后位置和领用日期。
3. 填写备注，必要时补充资产状态和附件说明。
4. 提交后，资产状态变为“领用”或“领用待签字”。
5. 开启员工签字时，员工需在 **签字** 页面核对资产信息后完成签字；签字后才视为完成确认。

### 6.2 退库

1. 在领用记录中选择需要退库的资产，点击 **退库**。
2. 填写退库日期、退库后位置和退库备注。
3. 确认实物、配件、外观和功能状态后提交。
4. 完成后使用人恢复为“未分配”，资产状态恢复为“空闲”。

### 6.3 交接

1. 选择当前已领用或借用的资产，点击 **交接**。
2. 选择交接类型：员工交接或公共区域交接。
3. 填写接收人、接收位置、交接日期和备注。
4. 员工交接如需签字，接收人到 **签字** 页面确认；公共区域交接按页面提示完成。
5. 交接撤回仅针对仍处于待签字的单据，撤回后资产恢复为发起交接前状态。

## 7. 借用归还

进入 **资产 > 借用归还**。

### 7.1 借用

1. 选择空闲资产，点击 **新增** 或 **借用**。
2. 选择借用人，填写借用日期、预计归还日期、借用后位置和备注。
3. 提交后状态为“借用”或“借用待签字”。
4. 开启签字时，借用人必须核对并签字确认。

### 7.2 归还与延期

- 归还时选择借用记录，确认归还日期、归还后位置、资产和配件状态后提交。
- 需要延长使用期限时使用 **延期**，填写新的预计归还日期和说明；延期不会替代实际归还操作。
- 归还完成后资产恢复为空闲状态，并保留借用和归还记录。

## 8. 审批与签字

### 8.1 审批

进入 **审批**：

1. 查看待处理、处理中、已通过、已驳回和已取消的申请。
2. 打开发起人、资产、事由、日期、位置和备注，确认信息完整。
3. 有审批权限时执行同意或驳回，并填写必要意见。
4. 审批通过后，系统按业务类型执行对应资产命令；审批状态和资产状态出现短暂差异时先刷新并查看审批单号。

### 8.2 员工签字

进入 **签字**：

1. 打开待本人确认的领用、借用或交接单。
2. 核对资产编码、名称、配置、配件、位置、日期和备注。
3. 确认无误后完成签字；发现问题先联系资产运营人员，不要提交错误签字。
4. 管理员可终止仍处于待签字的领用/借用单；交接单使用撤回交接处理。

## 9. 资产盘点

进入 **资产 > 资产盘点**。

1. 点击新建盘点任务，填写盘点名称、范围、位置、负责人和截止日期。
2. 发布任务后按资产编码逐项核对实物、位置、使用人和状态。
3. 对已核实资产执行盘点确认；对异常资产填写差异说明。
4. 盘点完成后查看盘点汇总和差异清单，再决定是否回到资产列表修正台账。
5. 盘点本身不自动改变资产责任人；台账修改必须通过资产业务操作或授权的编辑流程完成。

## 10. 资产处置

进入 **资产 > 资产处置**，或在资产列表选择空闲资产后点击 **处置**。

1. 仅选择确认空闲且不在审批、待签字或借用中的资产。
2. 填写处置原因、处置方式、申请日期、附件和备注。
3. 提交后资产进入“处置中”，按页面权限执行完成或取消。
4. 处置完成后资产变为“已处置”，不再出现在有效资产列表，但历史记录保留。
5. 处置取消前先确认实物和财务处理状态，避免重复建单。

## 11. 资产设置

进入 **资产 > 资产设置**。

### 11.1 位置管理

维护公司、园区、楼层、房间等资产位置树。新增或修改位置后，先确认已有资产是否使用该位置，再进行删除或停用。

### 11.2 资产分类

维护资产分类树和分类编码。分类名称、编码和层级会影响新增资产、导入校验和资产编码规则，变更前应先导出留档。

### 11.3 资产编码规则

配置编码前缀、参与字段、分隔符、日期格式和流水号长度。规则修改只影响后续自动生成的编码，不会自动重编号已有资产。

### 11.4 标签模板设置

配置资产标签纸张、标签尺寸、行列数、间距和打印字段。保存后先选择少量资产打印预览，确认二维码/编码、名称和分类位置均清晰，再批量打印。

## 12. 系统设置

### 12.1 员工信息与组织架构

员工信息和组织架构来自 ECP 目录。领用人、借用人、接收人应从有效人员中选择，不要手工输入同名人员替代正式身份。

### 12.2 员工自助

在 **系统 > 员工自助** 配置：

- 自助领用、退还、借用、归还和交接是否启用。
- 自助领用/借用/交接是否需要管理员审批。
- 可申请资产类别、备注是否必填及提示语。
- 领用、借用、交接、归还等场景的员工签字和须知内容。

修改后点击保存，并用员工自助账号验证一次完整流程。

### 12.3 系统对接

系统对接用于维护外部服务连接。创建或编辑连接时填写对接编码、名称、服务类型、服务地址、启用状态、访问密钥和 JSON 连接配置。密钥只由授权管理员维护，不写入文档、导出文件或聊天记录。

#### 老资产系统单向同步（约定方案）

启用同步前必须完成接口、字段映射和首次基线核对。启用后的约定如下：

- 方向固定为“老资产系统 -> 新资产系统”。
- 老系统继续作为资产基础资料唯一来源，可继续新增和编辑；同步读取不锁定老系统。
- 默认每天凌晨 **02:00（Asia/Shanghai）** 执行，使用变更时间窗口和安全延迟，避免读取正在提交的数据。
- 新系统保留资产审批、领用、退库、借用、归还、交接、签字和操作履历，不使用全量替换接口清空这些历史。
- 资产通过老系统稳定唯一 ID 匹配，禁止按名称、序列号或人员姓名猜测匹配。
- 老系统删除的资产在新系统先标记为已处置/来源已删除并保留历史，不直接物理删除。
- 同步失败的记录进入异常队列，修复接口或数据后重试；未完成核对前不批量停用资产。

每日检查建议：

1. 在 **系统 > 系统对接** 查看最近一次执行时间、窗口、读取数、成功数和失败数。
2. 成功数、失败数和老系统变更数不一致时，下载异常明细并记录处理结果。
3. 同步结束后抽查资产总数、资产编码、分类、位置、状态和金额汇总。
4. 发现同步异常不要手工在新系统补录同一资产，先处理唯一 ID 或映射问题。

### 12.4 表单管理

维护审批或业务表单定义。表单编码应保持稳定，JSON Schema 修改后先用测试申请验证，再启用到正式流程。

### 12.5 成员授权

在 **系统 > 成员授权** 管理应用角色和成员权限。授权遵循最小权限原则：只读人员不授予新增、修改、删除、处置或授权权限；权限变更后由被授权人重新登录验证菜单和按钮。

## 13. 操作记录与时间口径

资产详情中的操作记录按新记录在前、旧记录在后显示。每条记录包含操作时间、操作人、渠道、操作类型和操作内容。

- 有可靠事件时间时显示到 `YYYY-MM-DD HH:mm`。
- 只有历史日期时只显示 `YYYY-MM-DD`，不推断具体时分。
- 操作内容应说明资产、动作、人员/位置和结果，例如“张三办理笔记本电脑退库”，而不是只显示“修改”。
- 同步记录使用独立的“老系统同步”动作标识，不覆盖人工业务履历。

发现时间明显不合理时，先截图保存资产编码和记录内容，检查数据来源和原始单据，不要直接手工修改数据库时间。

## 14. 常见问题处理

### 页面白屏或一直加载

1. 刷新页面并重新登录。
2. 确认账号仍有目标菜单的查看权限。
3. 打开浏览器控制台记录首条错误、页面地址和操作步骤。
4. 不要连续重复提交表单；先确认后端是否已经写入。

### 操作按钮不可用

通常是账号缺少操作权限、选中的资产状态不符合要求，或资产处于审批/待签字状态。先检查权限和资产状态，不要绕过页面直接改数据。

### 导入失败

检查资产编码是否重复、分类和位置是否存在、人员是否为有效 ECP 身份、日期和金额格式是否正确，并按错误明细修正后重试。

### 同步失败

查看系统对接中的运行状态和异常队列，优先修复老系统接口、凭据、唯一 ID 或字段映射问题，再执行单条或整批重试。同步失败期间新系统仍可正常办理已有业务。

## 15. 操作前检查清单

- 是否确认了正确的资产编码和实物。
- 是否确认当前资产状态允许该操作。
- 是否选择了正确的人员、公司、部门和位置。
- 日期、预计归还日期和备注是否准确。
- 是否需要员工签字或审批。
- 是否需要打印单据、标签或导出留档。
- 批量操作是否已核对选中范围。
- 同步或导入是否已完成结果核对。

## 16. 管理员维护建议

1. 每日检查审批、签字、盘点和同步异常。
2. 每周抽查资产编码、状态、使用人、位置和操作记录的一致性。
3. 每月导出资产清单和业务异常清单留档。
4. 修改分类、位置、编码规则、签字设置或表单前，先导出当前配置。
5. 不使用“全量替换资产”清理日常数据；涉及同步、迁移或历史修复时先做备份和试运行。
